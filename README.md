# Solo, sementes & clima

Página única em português que resume as ideias do artigo **"'Agent Platform of 2027': Soil, Seeds, & Weather"**, de **Dan Batten** ([Infinite Garden](https://www.infinitegarden.ai)), escrito em resposta ao post ["Agent Platform of 2027"](https://x.com/john_ssuh/status/2124336124172935336), de John Suh.

- Artigo original: https://x.com/DanBatten/status/2125667463564234936

> Resumo independente em português; não afiliado ao autor. Todo o crédito das ideias a Dan Batten.

O texto é um explicador com palavras próprias, com poucas citações curtas atribuídas ao autor. Todas as ilustrações e diagramas (SVG, CSS e canvas) foram feitos para esta página. Sem rastreamento, sem analytics, sem fontes ou scripts de CDN externa (a fonte Fraunces é servida junto com o site).

## Rodar

```sh
npm install
npm run dev      # desenvolvimento
npm run build    # gera dist/
npm run preview  # serve dist/
```

Site estático feito com Vite (HTML, CSS e JavaScript puros).
